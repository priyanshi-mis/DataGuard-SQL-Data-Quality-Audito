# DataGuard — SQL Data Quality Auditor

A MySQL-based project to detect data quality issues and analyze customer transactions using SQL.

### Key Features
- Detects missing and duplicate customer data.
- Identifies invalid emails and age values.
- Finds negative amounts and invalid transaction statuses.
- Generates audit summaries and customer transaction reports.

### Tools
MySQL | MySQL Workbench | SQL

### SQL Concepts
Joins, Aggregate Functions, GROUP BY, HAVING, CASE WHEN, UNION ALL, and Regular Expressions.

### Project Files
- `DataGuard.sql` — Database setup, sample data, and audit queries.
- `screenshots/` — Query outputs and analysis results.

### Key Outcome
Built a SQL-based auditing system to identify data quality issues and summarize transaction performance.
